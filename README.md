# MIT Data Science & Machine Learning Projects

This repository contains a selection of projects I completed as part of the **MIT Data Science and Machine Learning course**.

I’ve uploaded them here to showcase some of the practical work I completed throughout the course and the different data science and machine learning techniques I worked with.

The projects cover areas such as:

- Exploratory data analysis and visualisation
- Data cleaning and preprocessing
- Feature engineering
- Regression and classification
- Machine learning model development
- Model evaluation and tuning
- Turning model results into practical insights and recommendations

Most of the projects were completed in **Python**, using libraries such as Pandas, NumPy, Scikit-learn, Matplotlib and Seaborn.

The project problems and datasets were provided as part of the course, with the analysis, modelling and interpretation completed as part of my coursework.

I’ve kept these projects here as a record of what I learned and as examples of how I approach data science problems from initial exploration through to modelling and final recommendations.
